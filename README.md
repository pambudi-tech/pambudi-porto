# Ivan Pambudi - The Portfolio

A standalone experiment in a fixed white surface and interactive cross-stitch. The default is the supplied simple corner ornament, traced as a 31 × 31 grid, rotated inward at all four corners. Each black reference square becomes one charcoal X. Subtle perforations indicate the stitchable grid. Cotton strands are drawn procedurally; there is no woven background texture.

```sh
git clone https://github.com/pambudi-tech/pambudi-porto.git
cd pambudi-porto
npm start
```

Open http://127.0.0.1:4317. Use `PORT=4318 npm start` to choose another port.

For production, `npm run build` copies the browser files and assets into `dist/`. `vercel.json` explicitly selects the Other framework preset and publishes that directory as a static site. `server.mjs` is only the local preview server and is excluded from the deployment output. A successful deployment build does not prove runtime health; verify that the production homepage and its JavaScript, fonts, and images return HTTP 200. A `FUNCTION_INVOCATION_FAILED` error is a runtime failure whose stack trace is in Vercel’s project Logs, rather than the build log.

`paper-material.mjs` adds fixed fine grain and matte lighting above the approved PNG and below the copy and seal. It composites the original image with grain directly, avoiding soft-light blending that loses contrast against near-white paper. Softened image luminance supplies an approximate relief response around the existing embossed detail; it is not a physical height map. Four directional textures encode bounded luminance changes, prepared once and composited as the existing motion settles. A broad diffuse light creates a visible light-to-shade transition as the pointer crosses the sheet. The overlay follows the PNG alpha, so transparent cutouts remain clear. Grain never animates or reseeds. Reduced motion retains static grain with no moving light. The original image remains the fallback if material preparation fails.

The lower paper oval holds the transparent wax seal image in `assets/works-wax-seal.png`, with an embossed lowercase “works” label in Syne Mono. `wax-material.mjs` reconstructs an approximate height and normal map from distances inside the actual PNG outline, with a rolled rim, recessed groove, inner lip, and image-derived fine detail. These are inferred surface features, not measured geometry. A pointer-controlled light is shaded against those normals in `wax-interaction.mjs`; the reflection takes its red pigment from the source image and uses CSS overlay blending to enrich the wax color and retain its texture. The quiet face and stronger rim reflection stay inside the original alpha, and the embossed label remains above them. There is no timed sweep or repeating animation. The wax reflection starts appearing within 100px of the oval before hover, with a smooth spatial falloff, a 240ms fade response, and 110ms pointer-follow response shared in `WAX_LIGHT`. The embossed label eases with the same light strength and direction. Keyboard focus uses a static light; reduced motion disables pointer-driven lighting. Drawing settles into its target and stops when still, reusing the shaded pixels while only the reflection opacity changes. The original image remains visible if enhancement fails. The seal scales with the paper, sits 2px above its initial placement, and darkens while pressed. Its native button events do not place stitches. A damped motion curve gathers briefly, flows faster, then decelerates through a long settling tail. The original photographic rim is uncovered naturally. The lowercase label begins its original smooth opacity and blur reveal when the eased wax spread reaches 50%, while the rim continues spreading. Its embossed lighting remains intact. Slightly different angular flow speeds give the front soft asymmetric scallops without pointed fingers or backward pulsing. Shared `WAX_ENTRANCE` values control timing. The temporary canvas and reveal styles are removed at completion so the original image, press behavior, and proximity reflection take over. - Click or tap the exposed surface to sew one random motif from the supplied references: pixel rose, green dinosaur, teal sword, red dragon, watermelon, lightning bolt, pink bow, yellow duck, or blue diamond. Each colored chart square becomes one X at the surface’s existing pitch. Motifs receive a random left or right tilt within −45° to +45° on each placement using their traced outlines and colors; they are not generated from geometric approximations.
- `motif-data.mjs` contains the traced charts. Original references and a side-by-side comparison live in `previews/motif-references/` and `/previews/motif-shapes.html`. `python3 tools/trace-motifs.py` regenerates the data using measured grid centers and a small palette per reference to remove compression noise. The first red embroidery photo supplies the thread-style direction; the rose and dinosaur use their later replacement images.
- `motifs.mjs` maps the source cells to the surface and staggers their stitch reveal from the center outward. A shuffled bag serves all nine motifs before reshuffling and prevents consecutive repeats. One motif is one undo action, including overlaps. Tilted templates are sampled back onto the shared lattice, with short bridges to keep thin stems and diagonal joins connected. Motifs sew below the paper and preserve anchored ornament stitches. The duck, watermelon, and rose use brighter thread palettes in `motifs.mjs`; the other six retain their traced colors.
- Right-click or long-press for the white stitch panel, with a Motif / Free stitch mode switch and undo/redo. Shift F10 or the context-menu key opens it with a keyboard. Dismissing the panel does not sew another stitch. The sage text-selection highlight is independent of the panel colors.
- Free stitch adds individual X stitches with a click, tap, or drag, using black by default. Fast strokes fill skipped grid cells; one complete stroke is one undo action. Touch waits to distinguish a tap, drag, and long-press. Drawing protects the paper and anchored ornament stitches, and crossing the paper breaks the stroke connection. Free stitches share the motif reveal layer and reduced-motion behavior through `free-stitch.mjs`.
- The Free stitch palette offers blue, yellow, red, green, purple, and black. A single Unpick toggle switches removal on or off. Unpick removes individual X stitches, including visitor motifs and anchored ornaments, by reversing their thread reveal beneath the paper. Each removal stroke remains one undo action and restores the exact previous colors. Choosing a color turns Unpick off. The last color and action persist while switching modes during the visit. `thread-colors.mjs` supplies shared colors; the bird's red uses the exact same `#c6434b` as the Red swatch.
- `stitch-panel.mjs` owns reusable panel motion through `STITCH_PANEL_MOTION`: a 240ms response with `cubic-bezier(.22, 1, .36, 1)`, shared with CSS as duration/easing tokens. Entry and exit ease opacity, position, and scale; the same persistent mode pill slides between options. The palette section expands and fades while preserving the panel's anchor side. Switching modes keeps the panel open. Closing makes it inert immediately, delays hiding until its exit finishes, and cancels that hide if reopened. Reduced motion makes these transitions immediate.
- Dragging, cancelled pointers, long-presses, and multi-touch do not place motifs. Paper and wax-seal presses keep their existing interaction.
- Hover uses the original faint X and four stitch-hole rings, snapping from cell to cell on the shared surface grid. Clicking still places a random motif at that cell.
- The surface has no pan or zoom controls or gestures. Corner motifs stay anchored to the page edges as the viewport changes. Visitor motifs retain ordinary integer lattice coordinates so a resize cannot split them across corner slots.
- A bird, reconstructed from the supplied cross-stitch animation, travels through the surface's actual dot grid. Its pattern is sampled at the same stitch spacing as the corner motifs and visitor stitches. Each X sews and withdraws in place as the bird changes cells; it is drawn on the embroidery canvas. Permanent embroidery keeps its cells. The bird never changes visitor embroidery or adds animation frames to undo history.
- On first load, the bird reveals from its center outward with the shared irregular flame pattern. The reveal follows its flight and wing poses. As stitches cross behind the centered paper they become a more vibrant leaf green, while the incoming tail retains its original red. On the return pass, stitches become red again as they emerge on the left.
- The bird pauses when reduced motion is preferred and suspends while the page is hidden.
- `wing-motion.mjs` keeps the approved raised silhouette and 100ms wingbeat rhythm, while curving the downstroke and delaying the wrist and feather tips. The far wing's inner feathers move from the shoulder instead of leaving a fixed horizontal strip beside the head. A separate torso contour keeps the back full between the tail root and neck when the wings drop; per-wing silhouette masks preserve the raised featherwork's decorative gaps. Transformed feather areas are sampled onto the original stitch grid. `bird-motion.mjs` then adds gentle breast lift and pitch, a steadier head, and delayed tail flex. Body targets update every 40ms through the existing sew/withdraw transitions. Reduced motion holds the complete current pose.
- `Cmd/Ctrl Z` undoes a complete motif or freehand stroke; `Cmd/Ctrl Shift Z` redoes it.
- Focus the surface and use arrow keys followed by Enter or Space to stitch in the selected mode with a keyboard.
- Every reload starts with the original ornaments and no visitor motifs. Undo/redo history belongs only to the current visit. The surface does not read or write browser storage, and old storage entries remain untouched.
- Reduced motion shows complete motifs immediately, including when the preference changes during stitching.
