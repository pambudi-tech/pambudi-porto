# Private work

Galleries and live sites of password-protected projects, served only to
visitors with a PIN pass (see server/works-pass.mjs). One folder per work id:

    private/works/<id>/gallery.json   a list like a case study's `gallery`
    private/works/<id>/01.webp        the images it names in `src`
    private/works/<id>/site.txt       its live site, for the "visit site" link

Nothing here is published to /assets or bundled into the page.
